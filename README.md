# Ally Financial (ally-financial)

Ally Financial is a digital financial services company providing automotive financing, online banking, mortgage, corporate finance, and brokerage products to consumers and businesses. As a digital-first bank, Ally participates in open banking data sharing through FDX (Financial Data Exchange) standards and partners with fintech aggregators for account connectivity.

**Website:** [https://www.ally.com/](https://www.ally.com/)

## Status

Ally Financial does not offer a public developer API portal. This repository tracks known integration capabilities including open banking data sharing with fintech aggregators and automotive dealer management system integrations.

## Capabilities

- **Open Banking Data Sharing** — Consumer-permissioned account data access via FDX standards and Dodd-Frank Section 1033
- **Automotive Finance Integration** — Dealer management system APIs for lending, leasing, and floorplan financing
- **Corporate Finance API** — Treasury management and corporate banking APIs for commercial clients
- **Dealer Management Integration** — Automotive dealer network APIs for retail lending and insurance

## Use Cases

- **Fintech Account Aggregation** — Data sharing with personal finance apps via Plaid, MX, and Finicity
- **Automotive Dealer Integration** — DMS connectivity for Ally automotive finance products
- **Treasury Management** — Corporate client APIs for account management and payment initiation

## Integrations

- Plaid — Account connectivity for consumer fintech applications
- MX Technologies — Financial data aggregation and account verification
- Dealer Management Systems — Automotive finance workflow automation
